# Guías y Notas Personalizadas de HestiaCP (PiruHost)

Este directorio contiene las guías, comandos de mantenimiento, notas de compilación y opciones de configuración creadas para este fork.

---

## Índice de Documentos

1. [INSTALL.md](file:///d:/Development/hestiacp/guias/INSTALL.md)  
   Guía de instalación autónoma y limpia desde código fuente en VPS nuevos (Debian / Ubuntu) sin dependencias externas.

2. [COMMANDS.md](file:///d:/Development/hestiacp/guias/COMMANDS.md)  
   Comandos frecuentes de compilación en caliente, permisos `chmod +x`, liberación de espacio en disco, configuración de SSL Let's Encrypt y whitelabel.

3. [GUIA_SINCRONIZACION.md](file:///d:/Development/hestiacp/guias/GUIA_SINCRONIZACION.md)  
   Instrucciones paso a paso para sincronizar este fork con el repositorio oficial (`upstream`) de HestiaCP.

4. [OPCIONES.md](file:///d:/Development/hestiacp/guias/OPCIONES.md)  
   Instrucciones para activar el Gestor de Archivos (File Manager), Single Sign-On (SSO) en phpMyAdmin, y Node.js / PNPM para despliegues.

5. [C2.md](file:///d:/Development/hestiacp/guias/C2.md)  
   Scripts rápidos de compilación, clonación y corrección de permisos en servidor.
