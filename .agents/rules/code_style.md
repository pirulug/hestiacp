# Reglas de Estilo y Estandares de Codigo

## Reglas Generales

* Uso de comillas:
  * Priorizar comillas dobles (`"`) para cadenas de texto en todos los lenguajes (Bash, PHP, JavaScript, CSS, JSON).
  * Emplear comillas simples (`'`) unicamente en casos estrictamente indispensables.
  * Mantener un uso consistente de las comillas en todo el codigo y la documentacion.
* Prohibicion de emojis:
  * No incluir emojis en codigo, mensajes de commit, comentarios, documentacion ni interfaces de usuario.
  * Solo utilizar emojis si el usuario lo solicita de forma explicita.
* Archivos Markdown (`.md`):
  * No utilizar `---` como separador horizontal bajo ninguna circunstancia.
  * Evitar separadores innecesarios.
  * Mantener el texto estructurado con encabezados claros, listas ordenadas/desordenadas y bloques de codigo.
* Claridad y profesionalismo:
  * Redactar explicaciones directas, tecnicas y concisas.
  * Preservar los comentarios existentes a menos que su modificacion sea requerida por la tarea.
